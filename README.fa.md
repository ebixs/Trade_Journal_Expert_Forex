# دفتر معامله

[English](README.md)

ژورنال شخصی برای MT4 و MT5. اکسپرت معامله‌ها را می‌خواند و به برنامه‌ای که روی کامپیوتر خودت اجرا می‌شود می‌فرستد. داشبورد فارسی آن‌ها را تحلیل می‌کند و قانون‌هایت را به‌صورت هشدار روی چارت نشان می‌دهد.

اکسپرت هیچ تابع ثبت یا بستن سفارش ندارد و داده‌ها فقط در `data/journal.db` روی کامپیوتر خودت می‌مانند.

## اجرا

به Python 3.10 یا جدیدتر نیاز داری. برنامه روی ویندوز و مک اجرا می‌شود.

| | ویندوز | مک |
|---|---|---|
| داده نمونه | `start-demo.bat` | `start-demo.command` |
| اجرای واقعی | `start.bat` | `start.command` |

بعد آدرس `http://127.0.0.1:8765` را باز کن.

اگر مک اجازه باز کردن فایل را نداد، روی آن راست‌کلیک کن و Open را بزن، یا در Terminal اجرا کن:

```bash
cd مسیر/پوشه/trade-journal
bash start.command
```

راهنمای وصل کردن متاتریدر داخل برنامه، در صفحه «اتصال متاتریدر» است و مسیر مناسب سیستم‌عاملت را نشان می‌دهد.

## میانبر دسکتاپ

یک بار اجرا کن: روی مک `bash install-shortcut.command` و روی ویندوز `install-shortcut.bat`. آیکون Trade Journal روی دسکتاپ ساخته می‌شود و برنامه بعد از ورود به سیستم خودکار در پس‌زمینه بالا می‌آید.

هر بار که آیکون را باز کنی، آخرین نسخه از GitHub گرفته می‌شود، سرور در صورت نیاز راه می‌افتد و ژورنال در مرورگر باز می‌شود. اگر اینترنت یا GitHub در دسترس نباشد، همان نسخه موجود باز می‌شود. گزارش این کارها در `data/launcher.log` است.

تغییر فایل اکسپرت خودکار وارد متاتریدر نمی‌شود و باید آن را جداگانه کپی و کامپایل کنی.

## بکاپ

هر روز یک نسخه از ژورنال ساخته می‌شود و ۳۰ نسخه آخر می‌ماند. مقصد پیش‌فرض iCloud Drive است و اگر نبود پوشه Documents. مسیر را در صفحه «هوش مصنوعی و منبع‌ها» می‌توان عوض کرد. کلید API در بکاپ نیست.

برای بازگردانی: برنامه را ببند، فایل بکاپ را با نام `journal.db` در پوشه `data` بگذار، فایل‌های `journal.db-wal` و `journal.db-shm` قبلی را پاک کن و برنامه را باز کن. کلید API را دوباره وارد کن.

## ساختار

| مسیر | کار |
|---|---|
| `ea/` | اکسپرت؛ یک کد مشترک برای `.mq4` و `.mq5` |
| `app/ingest.py` | ذخیره پیام‌های اکسپرت و ثبت تغییر SL و TP |
| `app/analytics.py` | ساخت معامله از دیل‌ها، آمار، نکته‌های رفتاری، پیشنهادها و هشدارها |
| `app/main.py` | API محلی |
| `app/static/` | داشبورد و تم‌ها |
| `tools/simulate_ea.py` | شبیه‌ساز اکسپرت برای تست بدون متاتریدر |

تست‌ها: `pip install -r requirements-dev.txt` و بعد `pytest`

## محدودیت‌های فعلی

- حساب هجینگ کامل پشتیبانی می‌شود. در حساب نتینگ، معکوس کردن پوزیشن ممکن است دقیق تفکیک نشود.
- تغییر SL و TP فقط وقتی ثبت می‌شود که اکسپرت روشن باشد.
- بهترین و بدترین قیمت هر معامله از کندل‌های M1 می‌آید، پس کمی تقریبی است.
- در ورود سابقه قدیمی، اختلاف ساعت تابستانی بروکر ممکن است زمان را یک ساعت جابه‌جا کند.
- در MT4 حد ضرر اولیه معامله‌های قدیمی در دسترس نیست و فقط آخرین مقدار ثبت می‌شود.
- تقویم اقتصادی MT5 رقم واقعی خبر را می‌دهد. روی MT4 فقط فایل هفتگی Forex Factory هست و رقم واقعی ندارد، پس شگفتی خبر حساب نمی‌شود.
- جهت‌های صفحه خبر واکنش معمول بازار است و پیش‌بینی نیست.

## خبر و هوش مصنوعی

- خبرها هر ۱۰ دقیقه و تقویم هر ساعت دریافت می‌شوند. وضعیت هر منبع در صفحه خبر دیده می‌شود.
- مسیر سرخط‌های CNN از Google News است، چون RSS خود CNN از ۲۰۲۴ به‌روز نمی‌شود.
- تنظیم سرویس هوش مصنوعی در صفحه «هوش مصنوعی و منبع‌ها» است.
- شماره حساب، نام و بروکر به سرویس هوش مصنوعی فرستاده نمی‌شود.
